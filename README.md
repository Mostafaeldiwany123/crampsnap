# Screenshot_mobileApp

College Lecture & Document Scanner App built with Expo, React Native, and Supabase.

## Features
- Minimalist academic camera deck with pinch-to-zoom and clean centered multiplier
- Custom bottom navigation bar with live photo preview thumbnail and solid tactile shutter button
- Smart study vault for categorizing lecture notes and whiteboards
- Instant PDF export of study notes
- Supabase cloud sync & offline storage
